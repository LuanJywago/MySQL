********* TCL - Transaction Control Language ********

🤖🗣️~Controle de transações, garantindo consistência dos dados.
🔹Comandos principais:

COMMIT — confirmar
ROLLBACK — desfazer
SAVEPOINT — criar pontos de restauração

###################################################################################################################################

START TRANSACTION;

UPDATE contas 
SET saldo = saldo - 100 
WHERE id = 1;

UPDATE contas 
SET saldo = saldo + 100 
WHERE id = 2;

-- Confirmar transação
COMMIT;

-- Caso algo dê errado, poderia usar:
ROLLBACK;

###################################################################################################################################
