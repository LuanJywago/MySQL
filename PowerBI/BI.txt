POWER QUERY
- Ferramenta de transformação e preparação de dados
- Usado bastante para fazer processo ETL
- Permite se conectar a diversas fontes de dados, transformem as informações e carreguem em diferentes destinos
- A interface dele facilita a manipulação de dados sem necessidade de escrever um código
- É possivel transformar, filtrar, remover colunas, mesclar tabelas e mais
- Utiliza código na linguagem M que pode ser ajustado manualmente para transformações mais avançadas.
